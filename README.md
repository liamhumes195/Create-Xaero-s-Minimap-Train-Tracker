# 🚂 Create Xaero Train Tracker

A Minecraft mod designed to bring Create train tracking to Xaero's World Map and Xaero's Minimap!

## ✨ Features

- 🚂 Track Create trains on your map.
- 🗺️ Find train locations while exploring.
- ⚙️ Designed for Create railway systems.
- 🧭 Built for Minecraft railway enthusiasts.

## 📋 Requirements

- **Minecraft:** Java Edition 1.21.1
- **Mod loader:** NeoForge
- **Required mods:**
  - [Create](https://www.curseforge.com/minecraft/mc-mods/create)
  - [Xaero's World Map](https://www.curseforge.com/minecraft/mc-mods/xaeros-world-map)
  - [Xaero's Minimap](https://www.curseforge.com/minecraft/mc-mods/xaeros-minimap)

Make sure you install versions compatible with Minecraft 1.21.1 and your NeoForge version.

## 📥 Installation

1. Install Minecraft Java Edition 1.21.1.
2. Install NeoForge.
3. Download and install the required mods listed above.
4. Download the Create Xaero Train Tracker `.jar` file.
5. Place the JAR in your Minecraft `mods` folder.
6. Launch Minecraft using your NeoForge installation.

## 🛠️ Building from Source

This project uses Java 21 and Gradle.

On Windows, open a terminal in the project folder and run:

```powershell
.\gradlew.bat build
```

To perform a clean build:

```powershell
.\gradlew.bat clean build
```

The compiled JAR will be located in:

```text
build/libs/
```
